# ![LPPL Tracker](https://img.shields.io/badge/BTC-LPPL%20Tracker-orange?style=for-the-badge&logo=bitcoin)

[English](README.md)

LPPL Tracker 是一个技术分析工具，用于把对数周期幂律模型拟合到加密货币、股票和大宗商品价格序列上。它可以帮助识别类似泡沫的价格行为，估计临界时间窗口，并比较不同资产的拟合质量。

LPPL 是 **Log-Periodic Power Law** 的缩写，中文常译为**对数周期幂律**。该模型也称为 **JLS 模型**，以 Johansen、Ledoit 和 Sornette 的名字命名。

## LPPL 建模的是什么

LPPL 模型把金融泡沫描述为一种正反馈过程。在泡沫阶段，价格可能以快于指数增长的速度上升，同时出现越来越频繁的振荡，并逐步接近某个临界时间。

LPPL 不预测精确的崩盘日期。它估计的是一个高风险窗口，表示当前价格状态更可能在该窗口附近破裂或切换。

## 核心公式

```math
\ln[p(t)] = A + B(t_c-t)^m + C(t_c-t)^m\cos[\omega\ln(t_c-t)+\phi]
```

## 参数

| 符号 | 含义 | 说明 |
| :-- | :-- | :-- |
| $p(t)$ | 时间 $t$ 的资产价格 | 模型拟合的是价格的自然对数。 |
| $t$ | 当前时间 | 本项目通常会把时间归一化为天。 |
| $t_c$ | 临界时间 | 模型估计泡沫最可能破裂或切换状态的时间窗口。 |
| $A$ | 接近 $t_c$ 时的期望对数价格 | 本项目使用 $\exp(A)$ 作为临界价格预测值。 |
| $B$ | 幂律趋势系数 | 对于上涨泡沫，常用约束是 $B < 0$。 |
| $C$ | 振荡幅度 | 控制价格围绕趋势振荡的强度。 |
| $m$ | 幂律指数 | 通常约束在 $0 < m < 1$。 |
| $\omega$ | 对数周期频率 | 控制 $t_c$ 前出现多少次振荡。 |
| $\phi$ | 相位 | 控制振荡的起始相位。 |

## 如何解读结果

- **拟合质量**：RMSE 越低，说明拟合曲线越接近实际对数价格，但不能只看 RMSE。
- **临界日期**：高风险窗口的中心估计，不是确定性预测。
- **临界价格预测**：由 $\exp(A)$ 得出；当拟合条件允许时，会给出简单置信区间。
- **信心指标**：来自嵌套窗口扫描。数值越高，表示越多窗口在过滤条件下得到有效 LPPL 拟合。

## 重要限制

- LPPL 是风险信号，不是交易信号。
- 模型对选取的时间窗口和初始条件敏感。
- 非泡沫阶段也可能出现假阳性。
- 很多历史泡沫在事后能很好地拟合 LPPL，但实时预测更难，需要谨慎解读。
